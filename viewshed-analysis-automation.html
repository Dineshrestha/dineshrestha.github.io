Viewshed Analysis at Project Scale

A validated single-site visibility study evolved into a reusable batch workflow for evaluating potentially visible transmission structures from approximately 90 cultural-resource sites represented by points, lines, and polygons.

One successful analysis revealed a scaling problem.

The first viewshed required roughly three hours to configure terrain, evaluate visibility, summarize project features, and assemble GIS and reporting outputs. Repeating that process manually for about 90 sites would require at least 270 hours—and line and polygon resources were more complex than a single point.

01 / GEOMETRY

Sites were not just points

Lines and polygons represented extended cultural resources. A midpoint or centroid could miss visibility occurring elsewhere along the feature.

02 / TERRAIN

Coverage crossed state boundaries

The initial elevation surface did not cover the complete corridor, requiring a continuous project-wide DEM and deliberate resolution testing.

03 / COMPUTE

Accuracy had a runtime cost

Dense observer sampling, high-resolution elevation, and retained intermediate rasters multiplied processing time and storage across the batch.

A repeatable path from site geometry to visibility results.

The workflow converts each resource into representative observer locations, limits structures to the site-specific search area, evaluates terrain and tower height, and consolidates the resulting visibility records for review.

01

Standardize sites

Validate identifiers, geometry, projection, and point, line, or polygon inputs.

02

Create observers

Use the feature location directly for points and multiple sampled locations for extended sites.

03

Limit structures

Select candidate towers within five miles of the full cultural-resource geometry.

04

Model visibility

Run terrain visibility with a six-foot observer height and structure-height information.

05

Summarize

Identify structures potentially visible from any sampled location within each site.

06

Deliver

Create GIS outputs, Excel summaries, and optional per-site visibility rasters.

CRITICAL DESIGN DECISION

Represent the entire site—not one convenient location

A line midpoint or polygon centroid represents only one viewpoint. A tower hidden from that location may still be visible from another part of the same cultural resource. Multiple observers were therefore distributed across extended geometry so “potentially visible from the site” reflected the site as a whole.

After testing denser alternatives, configurable 500-meter spacing balanced spatial representation with production runtime.

TERRAIN STRATEGY

Resolution was selected through performance testing

Ten-meter elevation tiles were downloaded, clipped to a corridor buffered beyond the five-mile search distance, and mosaicked into a continuous surface. Testing showed the cell count was too costly for a many-observer, many-site production run.

A project-wide 30-meter DEM dramatically reduced the processing burden while preserving a practical terrain surface for batch screening.

Automation controls the expensive parts.

The solution exposes the decisions that matter so another GIS analyst can rerun the study when sites, structures, terrain, or reporting needs change.

Mixed geometry support

Point, line, and polygon resources share one workflow while using geometry-appropriate observer generation.

Configurable sampling

Line and polygon spacing can be changed without rebuilding the analysis.

Structure-aware visibility

Tower identifiers and heights are incorporated rather than treating structures as ground-level points.

Optional raster retention

Per-site rasters can be preserved for QA or omitted to reduce disk I/O and storage during routine runs.

Consistent parameters

Observer height, search distance, DEM units, curvature, and refraction settings are explicit and repeatable.

Consolidated reporting

Site-to-structure results are assembled into reviewable GIS and Excel outputs instead of compiled manually.

PRODUCTION CONFIGURATION

Practical settings for project scale

  • 500 m line and polygon observer spacing
  • 30 m continuous project DEM
  • 6 ft observer height above ground
  • 5-mile structure search from actual site geometry
  • Optional visibility/AGL raster outputs
  • Standardized identifiers and geometry checks

RESULT

A three-hour, one-site process became a practical 90-site workflow.

By redesigning observer placement, terrain resolution, output retention, and reporting as one system, the workflow reduced the conservative labor estimate from 270+ hours to approximately 16 labor hours—while making the methodology consistent, transparent, and reusable.
